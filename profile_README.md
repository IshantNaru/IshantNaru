## Selected Work

**[RetinaReplay](https://github.com/IshantNaru/RetinaReplay)** &nbsp;·&nbsp; fMRI → Visual Reconstruction  
Reconstructed visual perceptions from brain fMRI signals using lightweight MLP encoders paired with Stable Diffusion. Outperformed the CVPR 2023 baseline by **28–152%** across reconstruction metrics. MSc thesis, University of Birmingham.

**[TomRiddlesDiary](https://github.com/IshantNaru/TomRiddlesDiary)** &nbsp;·&nbsp; RAG Q&A System  
Document-aware chatbot over PDFs, research papers, and ebooks. Built with LangChain, Pinecone vector store, Groq LLaMA, and cross-encoder reranking for precision retrieval.

**[AQI Dashboard](https://github.com/IshantNaru/AQI-dashboard)** &nbsp;·&nbsp; Multi-source Air Quality Monitor  
Desktop app (PySide6) + companion PWA that queries four independent sensor networks, computes a consensus AQI via median across sources, and resolves any locality search through OpenStreetMap geocoding.
